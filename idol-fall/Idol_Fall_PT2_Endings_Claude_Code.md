# Action 处理逻辑建议

为了避免错误嫌疑人的 4 种 action 产生 20+ 篇几乎重复的长结局，建议：

- **贺寻**：保留 4 个完全不同的专属结局，即 ENDING 01–04。
- **沈溪 / 林安 / 陈屿 / 苏昭 / 银河星途**：主体使用各自 ENDING
  05–09；根据 action 只替换结尾前的一小段“传播后果”：
  - `public` 实名公开：网络迅速锁定该人，出现人肉/切割/舆论定罪。
  - `article`
    报道不点名：舆论根据细节自行猜到对象；伤害较慢，但错误叙事仍被固化。
  - `private`
    私下交给陪你走到最后：没有大规模传播，但错误方向让调查停在这里。
  - `nothing` 什么都不做：不产生公共伤害，但玩家也没有继续追到真正缺口。
- **unclear**：无论
  action，优先进入《没有一个名字》；如果代码结构允许，可让 action
  只改变最后 2–3 段，不改变核心结局。
- 不要在错误结局最后出现“真正的凶手其实是贺寻”。
- 每个错误结局只给一个未解释裂缝：
  - 沈溪 → `02:14` 删除后台记录需要内部权限。
  - 林安 → ECHO 中被移除的 `HX_404`。
  - 陈屿 → 真想灭证为何保留原始 F03/F04。
  - 苏昭 → 宠物医院记录覆盖死亡窗口；23:46 另有人进入。
  - 银河星途 → 结构责任成立，但 23:46 的具体进入者仍未回答。

# 页面表现建议

结局页不要一次性把全文砸出来。

建议按段落逐段淡入，贺寻《被删除的第五人》尤其可以把时间作为视觉锚点：

`19:26 → 20:36 → 21:06 → 21:47 → 22:11 → 23:12 → 23:31 → 23:36 → 23:39 → 23:43 → 23:46 → 23:47 → 23:52 → 00:11 → 02:14`

其中： - `23:52` 单独占一屏/一个明显断点。 - `02:14`
再做一次断点，因为这是“失控行为”转向“主动掩盖”的关键。 -
不要使用“凶手揭晓”“真相大白”等 UI。 - 结尾统一只给：`重新调查`。 -
可以保留玩家最终选择的小字记录，例如： `你的判断：贺寻 / 写报道但不点名`
但不要加系统评价。
