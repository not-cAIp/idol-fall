# 偶像的陨落

**[▶ 开始游戏](https://not-cAIp.github.io/idol-fall/)**

仿真微博社交平台调查解密游戏。顶流艺人周晏星坠亡，官方通报是"意外"——从超话帖子、私信记录和几个关联站点里挖出真相。

## 玩法

- 搜索账号、点开帖子和评论，拼出线索
- 找到关键证据后，通过私信「陪你走到最后」提交你的推理
- 结局取决于你找到了什么、又相信了什么

## 技术栈

Vite + 原生 JS，内容数据驱动（`content/*.json`），GitHub Actions 自动部署到 GitHub Pages。
